A pre-token protocol board (model `radar-m2`): every protocol without a trading token is scored by one
formula from its TVL, category peer FDV/TVL norms, growth, and tenure; wrapped, staked, bridged and
exchange products are set aside. The entry reads the sealed input snapshot and writes `board.json`,
`data.js`, `dossier.json`, an interactive `dashboard/` and three screenshots to `/output`.

## Run it

```sh
node --experimental-strip-types main.ts
```
