Model

Every pre-token protocol is scored by the same five factors. No name is special-cased.

  1. peer multiple median market cap / TVL of same-category protocols whose token trades
  2. size curve 0.9 × (TVL / $100M)−0.18, held to 0.25–2.2
  3. sector 0.55 × peer + 0.45 × size curve
  4. momentum 1 + 0.0035 × 7-day growth, clamped ±50 / +100%
  5. tenure 0.55 + 0.45 × min(age, 4y) / 4y

implied value = TVL × sector × momentum × tenure
